# StockSprint Pro

Responsive web/mobile-style virtual stock market learning and paper-trading application.

## Run in Antigravity
1. Extract/open this folder.
2. Install Node.js 18+.
3. Run `npm install`.
4. Run `npm start`.
5. Open `http://localhost:3000`.

## 300 automated test cases
Run `npm test`. The suite executes 300 API smoke/functional requests.
